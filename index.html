🌐 Online Sharing — How Collaborators Can Help

  1. Open the online link on any phone or laptop — no install needed.
  2. Review questions in Tab 1 or 3 and click "✏️ Edit" to correct answers, lessons, or question text.
  3. Export Edits — Click "📥 Export Edits" in the top bar. It downloads a tiny forensic_edits_*.json file.
  4. Send the JSON file via WhatsApp / Telegram / Email.
  5. You click "📤 Import Edits" in your local visualizer → their corrections are applied instantly!

📁 File Architecture

MCQs\
├── *.pdf                          # 24 original forensic textbooks
├── pipeline_out\
│   ├── chunks_full\               # Raw Gemini extraction chunks
│   ├── linked\                    # Key-linked questions per book
│   ├── df_final.pkl               # Deduplicated master dataset
│   └── Filtered_Toxo.xlsx         # Excluded toxicology questions
└── visualizer\
    ├── data\
    │   ├── books.json             # 24 book metadata
    │   ├── clusters.json          # 2,129 merged duplicate clusters
    │   ├── questions_summary.json # 5,585 final MCQs
    │   └── by_book\*.json         # Per-book for fast lookup
    ├── server.py                  # Local Python server
    ├── index.html                 # This app
    └── web_dist\                  # Deploy to GitHub Pages
