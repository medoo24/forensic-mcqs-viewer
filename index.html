🌐 Online Sharing & Exporting Lessons per Book

  1. Search in Tab 1: Type any keyword or question number in the search box in Tab 1 to filter questions and highlight matching pages across the book.
  2. Collapse / Expand MCQs: Click any MCQ's header or the ▼ / ▶ button to collapse it into a single clean line. Use "⊟ Collapse All" to collapse or expand all questions at once.
  3. Select Multiple Lessons: Click on the Lessons dropdown in Tab 1, 2, or 3 to check one or more lessons simultaneously.
  4. Export Book Lessons: Click "📥 Export Book Lessons" in Tab 1 to download all questions for your selected lessons from the currently opened book as a standalone JSON file.
  5. Review & Edit: Review questions in Tab 1 or 3 and click "✏️ Edit" to correct answers, lessons, or question text.
  6. Export Edits: Click "📥 Export Edits" in the top bar to export collaborative reviewer corrections.

📁 File Architecture

MCQs\
├── *.pdf                          # 24 original forensic textbooks
├── pipeline_out\
│   ├── chunks_full\               # Raw Gemini extraction chunks
│   ├── linked\                    # Key-linked questions per book
│   ├── df_final.pkl               # Deduplicated master dataset
│   └── Filtered_Toxo.xlsx         # Excluded toxicology questions
└── visualizer\
    ├── data\
    │   ├── books.json             # 24 book metadata
    │   ├── clusters.json          # 2,129 merged duplicate clusters
    │   ├── questions_summary.json # 5,585 final MCQs
    │   └── by_book\*.json         # Per-book for fast lookup
    ├── server.py                  # Local Python server
    ├── index.html                 # This app
    └── web_dist\                  # Deployed to GitHub Pages (includes full images)

🚀 Commands Reference

# Launch local visualizer:
python visualizer/server.py

# Re-export after editing chunk files (zero API calls):
python export_visualizer_data.py

# Re-run key linking:
python run1b.py
